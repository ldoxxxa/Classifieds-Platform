# Classifieds Platform — Full-Stack Web Application

**Semester project for the “Web-Based Applications” course**  
Hochschule RheinMain | Sommer Semester 2026

---

## 📌 About the Project

Classifieds Platform is a full-stack web application for creating and managing classified ads. It combines a Vue.js frontend with a Spring Boot backend, persistent data storage, and real-time updates.

The project covers the complete development process, from database models and API endpoints to the user interface.

---

## ✨ Features

- Create, browse, and manage classified ads
- Store listings using JPA and an H2 database
- Connect the frontend and backend through a REST API
- Deliver real-time updates through WebSockets

---

---

## 🧩 Architecture

The application separates the frontend, backend, and persistence layers.

- **Frontend:** displays listings and handles user interactions
- **Backend:** processes requests and implements application logic
- **Persistence:** manages database entities and stores listing data

The frontend communicates with the backend through REST endpoints and receives real-time updates through WebSockets.
